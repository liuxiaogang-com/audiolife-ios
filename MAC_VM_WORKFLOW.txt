Each run
  1. Collect tracked and nonignored source/scripts (including local uncommitted edits).
     Exclude .git, Xcode user state, build caches, device backups, and credentials.
  2. Create a source snapshot and per-file SHA-256 manifest on Windows.
  3. Copy over SSH and verify every source hash on the Mac.
  4. Run Xcode analyze and unsigned arm64 Release build for iPhone.
  5. Build for Simulator, install in a new dedicated simulator, launch, check the
     process remains running, take a screenshot, and shut down that simulator.
  6. Package the with-widget unsigned IPA. If Live Activity is disabled in the
     app, also package a nowidget variant by removing the extension from a copy.
     Live Activity builds require the extension and do not produce a nowidget IPA.
  7. Download output/logs and verify IPA SHA-256 again on Windows.

Results
  .build\mac-vm\<run-id>\output\
    build-info.json: source commit, dirty state, toolchain, validation scope, hashes
    source-manifest.json: exact files uploaded and their hashes
    *-with-widget-unsigned.ipa: full build with the Control Center Widget extension
      and, when enabled, Live Activity / Dynamic Island
    *-nowidget-unsigned.ipa: extension removed for the previous sideloading route
    *.ipa.sha256: artifact checksums
    simulator-home.png: actual simulator startup screenshot
    workflow.log / analyze.log / release.log / simulator-build.log: diagnostics
  Build output is ignored by Git. Scripts/documentation can be reviewed and committed
  separately; this workflow never commits, pushes, or installs to a physical phone.

Options
  -SkipSimulator: compile/analyze/package only; report marks simulator checks skipped.
  -MacHost, -MacUser, -IdentityFile, -RemoteRoot: connection/workspace overrides.

Validation boundaries
  The existing project has no XCTest target; startup smoke validation is not a unit
  test suite. Microphone, real recording, speech recognition, lock screen, Dynamic
  Island, signing, and phone installation require separate acceptance checks.
  Both IPAs are unsigned and require signing before physical-device installation.
  Each run retains its Mac snapshot, build cache, logs and dedicated simulator for
  diagnosis. These can be cleaned up deliberately after they are no longer needed.

VMware network workaround
  This VM's TCP segmentation offload causes very slow Mac-to-Windows downloads.
  Initialize-MacVm.ps1 checks net.inet.tcp.tso and, for xiao@192.168.159.135 only,
  sets it to 0 using the local encrypted sudo credential when needed.
  This is a runtime-only sysctl change; no boot configuration or sudo policy is edited.
  Mac restart restores the OS default; the next build applies the workaround again.
  To restore the default manually: sudo sysctl -w net.inet.tcp.tso=1

  and migration-expectations.json. Keep fixtures and private data outside Git.
